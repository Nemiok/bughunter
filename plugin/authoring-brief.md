# Бриф автора Bughunter-пресета

Заполните поля и передайте этот файл агенту одним сообщением. Пути `installPath` и `core` возьмите из `qwen plugins list --json` (поле `installPath`).

## Цель

- Домен: <например, CLI для миграций, HTTP job queue, мобильный API>
- Целевое приложение: <что запускается и где лежит>
- Фикстура для приёмки: <каталог с минимальным приложением>
- Засеянные дефекты: <C1…C4: что сломано и как это наблюдается>
- Что считается симптомом: <коды, тексты, аномальные токены>
- Ожидаемый контракт и формы check: <что должно быть верно>
- Критерий приёмки: найти ≥ <N> из <M> засеянных, 0 подтверждённых ложных, на каждый подтверждённый — red-тест, перепроверенный независимым запуском.

## Материалы

- Шаблон: `<installPath>/template/cli-preset`
- Core: `<installPath>/server/core`
- Скиллы: `bughunter:bughunter-preset-guide`, `bughunter:bughunter-core-contract`
- Пример брифа и порядок работы: `<installPath>/AUTHORING.md`

## Ограничения

- Не менять `core`; специфика — только в пресете, профиле и фикстуре.
- Не ослаблять приёмку и не выдавать непроверенное за проверенное.
- Не коммитить состояние (`runs/`, `auth/`) и не менять код целевого приложения.
