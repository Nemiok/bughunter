---
name: bughunter-setup
description: Настраивает локальный Bughunter MCP в проекте после явного выбора пресета.
---
Спроси пользователя `web` или `node`. После явного выбора вызови `mcp__bughunter__bh_setup` с `preset`. При `CONFIG_CREATED` покажи configPath и попроси заполнить config, затем выполни `/plugins reload` или открой новую сессию. При `BUGHUNTER_PROJECT_UNKNOWN` остановись: хост поднял сервер без сигнала рабочего проекта (проверено для Qwen Code 0.28.0 — extension MCP стартует с cwd = корень установки); не повторяй вызов и не создавай файлы сам. Настройка проекта через такой хост не сертифицирована — используй среду, где сервер видит проект, или явный `BUGHUNTER_PROJECT_ROOT`. Не выбирай пресет сам. Не обещай автоматический full workflow, native reviewer/test-writer agents или сертифицированный прогон. Отдельные MCP calls разрешены только в рамках схемы и серверных защит.
